`main.py` writes one original funny line — a joke about Monday mornings — to `/output/entry.txt` and prints it.

> Monday morning, my coffee took one look at my inbox and asked HR for a transfer to Friday.

90 characters, one line. Standard library only, no network, deterministic.

## Run it

```sh
python3 main.py
```
